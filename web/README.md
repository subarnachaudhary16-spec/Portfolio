# Subarna Chaudhary - Developer Portfolio

A modern, high-performance developer portfolio showcasing full-stack projects, technical capabilities, and interactive motion design.

## ✨ Features & Architecture

- **Clean Engineering Aesthetic**: Architectural design system with crisp geometric buttons, refined typography, and zero generic template clutter.
- **Light Mode & Night Mode**: One-click smooth toggle between Night Mode and Light Mode with persistent `localStorage` support.
- **Subtle Spotlight Glow & Perspective Motion**: Smooth, controlled perspective elevation on hover with mouse-tracking radial spotlight glow.
- **Top Reading Depth Bar**: Real-time reading depth indicator at the top of the viewport.
- **Interactive Terminal Widget**: Interactive developer terminal in the About section with one-click copy.
- **Technical Stats & Counters**: Animated count-up metrics for completed projects, commits, and experience.
- **Infinite Tech Marquee**: Seamless scrolling ticker highlighting modern web technologies and frameworks.
- **Project Filtering & Quick View Modal**: Filter projects by categories (*Full Stack, Frontend, Real-Time*) and view architectural breakdowns.
- **AJAX Contact Form & Toast Notifications**: Non-reloading form submission to Web3Forms with loading spinner states and floating toast feedback.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally using any static file server:

```bash
# Using Node / NPX
npx serve .

# Or open directly in browser
start index.html
```
